# CampusMart — UX Design

## App map

The app map shows the main screen hierarchy. Related interaction states appear with their parent screens in the wireframes below.

![CampusMart app map](<ux-design/AppMap.png>)

## Wireframes

These mobile wireframes follow the main student flows, from account access and service discovery to bookings and listing management.

### Account access and verification

#### Sign in

Students enter their account credentials.

![Sign in](<ux-design/Sign in.png>)

#### Sign in: invalid credentials

Shows the error and lets a student try signing in again.

![Sign in: invalid credentials](<ux-design/Sign in invalid credentials.png>)

#### Register

Students create an account with a university email address.

![Register](<ux-design/Register.png>)

#### Register: invalid university email

Explains why an email address does not meet the university requirement.

![Register: invalid university email](<ux-design/Register/invalid university email.png>)

#### Verification code sent

Students enter the code sent to their university email.

![Verification code sent](<ux-design/Verify university email/code sent.png>)

#### Verification code resent

Confirms that a replacement code was sent and asks for the latest code.

![Verification code resent](<ux-design/Verify university email/code resent.png>)

#### Change verification email

Lets a student correct the email address used for verification.

![Change verification email](<ux-design/Verify university email/change email.png>)

#### Email verified

Confirms successful university email verification.

![Email verified](<ux-design/Verify university email/verified.png>)
